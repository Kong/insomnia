# Roadmap

Goal: every Insomnia and Bruno feature in one app, local-first, with no account, telemetry or vendor service.

Tasks, priorities and open questions are in the [wiki roadmap](https://github.com/outmanos/restless/wiki/Roadmap), generated from [`docs/wiki/Roadmap.md`](docs/wiki/Roadmap.md).

| 0.4.0 | Daily workflow |
| 0.5.0 | Testing |
| 0.6.0 | Protocols and auth |
| 0.7.0 | API lifecycle |
| 0.8.0 | Developer tools and AI |
| 1.0.0 | Polish, signing and distribution |
